docs-ssh

Documentation over SSH for AI coding agents

$ssh -p __PORT__ docs@__HOST__

A self-hosted SSH server serving __SOURCE_COUNT__+ documentation sources as searchable markdown. Your AI agent connects over SSH and uses the tools it already knows — rg, bat, tree — to search and read docs with the same interface it uses for your code.

SSH config

Add this to ~/.ssh/config to skip the port and user on every command:

Host __HOST__
  User docs
  Port __PORT__
  StrictHostKeyChecking no
  UserKnownHostsFile /dev/null
  LogLevel ERROR

Then all commands simplify to ssh __HOST__ ...

Quick setup

  1. Install custom tools for your agent 
    # OpenCode — custom tools + rules
$ ssh __HOST__ tools > .opencode/tools/docs.ts
$ ssh __HOST__ agents >> AGENTS.md
# Claude Code / Cursor / Gemini
$ ssh __HOST__ agents claude >> CLAUDE.md
  2. Or pipe the setup guide to your agent 
    $ ssh __HOST__ setup | opencode
  3. Or just explore 
    $ ssh __HOST__ "rg -i 'RLS' /docs/supabase/"
$ ssh __HOST__ "bat --plain --paging=never /docs/postgres/indexes.md"
$ ssh __HOST__ "tree /docs/cloudflare/ -L 2"
  4. Chat LLM? Add the remote MCP endpoint

    Claude.ai / ChatGPT connectors can't SSH — point them at the Model Context Protocol endpoint, which exposes the same docs_* tools:

    https://__HOST__/mcp

Built-in commands

ssh __HOST__ help            # Usage and examples
ssh __HOST__ sources         # List doc sets with file counts
ssh __HOST__ agents          # AGENTS.md (raw SSH patterns)
ssh __HOST__ agents pi       # Pi format (docs_* extension tools)
ssh __HOST__ agents opencode # OpenCode (uses custom tools)
ssh __HOST__ agents claude   # CLAUDE.md format
ssh __HOST__ agents skill    # SKILL.md with YAML frontmatter
ssh __HOST__ agents help     # Show all output formats
ssh __HOST__ tools pi        # Pi extension (TypeBox / docs_* tools)
ssh __HOST__ tools           # OpenCode custom tools (rg --json, bat)
ssh __HOST__ setup           # Interactive setup guide
